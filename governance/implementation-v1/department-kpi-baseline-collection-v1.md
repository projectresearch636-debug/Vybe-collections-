# CEO HQ — Department KPI Baseline Collection v1

## Purpose

Collect verified baseline data for the 18 departments covered by the approved Department KPI Ownership Matrix v1.

This document is a controlled data-collection template. It does not invent performance values or targets.

## Data Integrity Rules

- Every numerical value must be traceable to an approved source.
- If data is unavailable, enter **TBD** rather than estimating.
- If a KPI is not applicable, enter **N/A** and explain why.
- The baseline period must be explicitly stated.
- KPI formulas and definitions must match the approved KPI framework.
- Proposed targets require supporting rationale and CEO HQ approval before becoming official targets.

## Required Submission Fields

For every KPI, submit:

| Field | Requirement |
|---|---|
| Department | Owning department |
| KPI | Exact KPI name |
| Definition | Unambiguous business definition |
| Formula | Calculation method, where applicable |
| Baseline Period | Exact dates/month/quarter |
| Baseline Value | Verified historical/current value or TBD |
| Unit | %, currency, count, days, ratio, etc. |
| Data Source | System/report/document used as evidence |
| Data Owner | Person/role accountable for source data |
| Reporting Frequency | Weekly / Monthly / Quarterly / Exception |
| Proposed Target | Proposed value or TBD |
| Target Rationale | Evidence supporting proposed target |
| Escalation Threshold | Threshold requiring executive attention |
| Dependencies | Other departments/systems required |
| Evidence Reference | File/report/link identifier |
| Verification Status | Pending / Verified / Rejected |
| Last Updated | Date of submission |
| Notes | Exceptions or context |

## CEO HQ Validation Gate

A submitted baseline is **Verified** only when:

1. The source is identifiable.
2. The measurement period is explicit.
3. The calculation matches the KPI definition.
4. The responsible department confirms the value.
5. Any material exception is documented.

## Target Approval Gate

Proposed targets remain **Proposed** until CEO HQ reviews:

- Baseline performance
- Historical trend
- Capacity constraints
- Financial implications
- Customer impact
- Strategic relevance
- Cross-department dependencies

## Executive Reporting Cadence

- **Weekly:** Critical operational KPI submissions and exceptions.
- **Monthly:** Complete baseline/actual review and variance analysis.
- **Quarterly:** Target review and OKR alignment.
